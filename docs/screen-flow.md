# 画面遷移（MVP）

最終更新: 2026-09-10

## 1. 認証
- ログイン/新規登録
- 利用規約・ガイドライン同意
- 年齢確認ステータス案内

## 2. ホーム
- 募集案件一覧
- 絞り込み（日時/エリア/予算/不足枠/年齢帯/所属カテゴリ）
- 「募集を作成」ボタン

## 3. 募集作成
- 必須項目入力
- プレビュー
- 公開

## 4. 案件詳細
- 募集条件表示
- 応募一覧（幹事単位）
- 承認/却下

## 5. 応募作成
- 提供可能枠
- 年齢帯構成
- 所属カテゴリ構成
- 補足コメント

## 6. 案件ルーム
- 幹事間チャット
- 開催情報の最終確認
- 開催済みフラグ

## 7. クローズ
- 開催後一定時間でルーム自動クローズ
- 評価/通報導線

## 8. 通報
- 案件通報
- ユーザー通報
- 理由カテゴリ選択
