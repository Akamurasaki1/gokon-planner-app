# 利用規約ドラフト（簡易版）

最終更新: 2026-09-10

> 注意: 本文はドラフトです。公開前に必ず法務確認を行ってください。

## 第1条（目的）
本サービスは、飲み会・交流会等の開催において、幹事間で不足人数の補充および開催調整を行うための支援を目的とします。

## 第2条（禁止事項）
ユーザーは以下を行ってはなりません。
1. 営業、勧誘、金銭要求、宗教・政治活動
2. 迷惑行為、ハラスメント、差別的行為
3. 法令違反または公序良俗に反する行為
4. 虚偽情報の登録
5. 本サービスの目的外利用（個人探索・1対1接触の執拗な要求など）

## 第3条（年齢制限）
18歳未満は利用できません。運営は必要に応じて年齢確認を求めることがあります。

## 第4条（アカウント管理）
ユーザーは自身のアカウント情報を適切に管理する責任を負います。

## 第5条（通報・措置）
運営は、違反通報を受けた場合または違反を確認した場合、警告・投稿非表示・利用停止等の措置を行うことができます。

## 第6条（免責）
運営は、ユーザー間トラブルについて可能な範囲で対応しますが、結果を保証するものではありません。

## 第7条（規約変更）
運営は必要に応じて本規約を変更できます。重要な変更はアプリ内で告知します。
