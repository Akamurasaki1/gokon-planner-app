# 募集フォーム項目案（必須/任意）

最終更新: 2026-09-10

## A. 募集案件（EventRequest）

### 必須
- 開催希望日（複数候補可）
- 開催エリア（都道府県/主要駅）
- 開催時間帯（夜/昼 など）
- 予算帯（1人あたり）
- 募集する不足枠
  - 例: 男性2枠 / 女性1枠
- 参加予定合計人数（見込み）
- 年齢帯（希望）
  - 例: 20-24 / 25-29 / 30-34
- 所属カテゴリ（希望）
  - 例: 大学生（文系/理系）・大学院生・社会人
- 禁止事項同意チェック（勧誘/営業/迷惑行為禁止）

### 任意
- 店舗候補
- 会の目的（交流メイン、友人づくり等）
- ドレスコード
- 幹事コメント（200文字程度）

## B. 幹事プロフィール（Organizer）

### 必須
- 表示名（ニックネーム可）
- 年齢確認ステータス
- 主な所属カテゴリ
- 活動エリア

### 任意
- 自己紹介（短文）
- アイコン画像（顔写真必須にしない）

## C. 応募フォーム（Application）

### 必須
- 提供可能枠（例: 女性2枠）
- 参加メンバーの年齢帯構成
- 参加メンバーの所属カテゴリ構成
- 連絡可能時間

### 任意
- 補足コメント

## 運用ルール（重要）
- 生年月日などのセンシティブ情報は公開しない（運営保持のみ）
- 個人単位での検索機能は提供しない
- 案件終了後、連絡ルームは一定期間で閉鎖する
